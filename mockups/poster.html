Pass / Fail Grading System

Mobile-first field grading & automated daily reporting · built for graders, zero training

PIN → Topic → Lock Sides → Companies → Build Groups → Grade → Repeat → Auto-Email Reports
1 · Grader PIN sign-in
2 · Pick topic
3 · Session setup (lock sides)
4 · Pick companies
5 · Build groups (tap chart)
6 · Grade: Pass / Fail / Memo
7 · Fail reveals reasons + note
8 · Round complete (run again)
9 · Admin / config (all editable)
10 · Emailed report (PDF)
Prototype UI · all data is configurable in-app · nothing hard-coded
